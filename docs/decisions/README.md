# Architecture decisions

This directory records decisions that shape the Application Delivery Kit.

Use a decision record when a choice has meaningful consequences for structure, ownership, portability, accessibility, or future maintenance.

Each record should state:

- status and date;
- context and problem;
- decision;
- alternatives considered;
- consequences;
- conditions that would justify revisiting it.

Ideas that are not yet accepted belong in a proposal or issue rather than being presented as settled architecture.
