# Navigation workflow slices

> Three focused pages showing when each navigation arrangement earns its place.

These pages deliberately separate the navigation workflows instead of combining every navigation area into one dense example.

## Choose a workflow

- [Simple navigation](./navigation-simple.md) — Header, primary navigation, mobile menu, and Footer.
- [Secondary navigation](./navigation-secondary.md) — Header, a short peer-link row, mobile menu, and Footer.
- [Sidebar navigation](./navigation-sidebar.md) — Header, a grouped Sidebar, mobile menu, and Footer.

## Shared contract

Every slice must preserve:

- semantic navigation landmarks with distinct names;
- real links for navigation destinations;
- visible current-page state where a page context exists;
- keyboard access and visible focus;
- a working skip link to Main;
- a mobile menu that preserves the available destinations without duplicating a second desktop rail;
- Footer links that support the page without competing with primary navigation.

The three pages use the existing layout components. They do not add new navigation primitives.
